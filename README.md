# NixOS Configuration

This repository contains a reusable set of NixOS defaults intended to provide a simple, maintainable desktop experience for everyday users.

## Folder Structure on target machines

/etc/nixos/
- **`flake.nix`** — Defines the NixOS system configuration and its inputs.
- **`configuration.nix`** — Room for personal touches.
- **`hardware-configuration.nix`** — Autogenerated hardware configuration file.
- **`defaults/`** — Reusable configuration modules providing recommended defaults for regular desktop users, such as GNOME, networking, automatic updates, and system maintenance.
- **`defaults/configuration.nix`** — Entry point to default settings. Loads the other modules in the folder.
